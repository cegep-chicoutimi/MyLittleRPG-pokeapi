# Utilisation de l'API MyLittleRPG

| Endpoints              | Type   | Description                                                                                               | Paramètres                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------- | ------ | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ``/api/Monstre``      | GET    | Permet d'aller récupérer <br>toutes les informations de tous monstres de la base de données.              | Ne prend pas de paramètre                                                                                                                                                                                                                                                                                                                                    |
| ``/api/Monstre``      | POST   | Enregistrer un nouveau <br>monstre dans la base de<br>données.                                            | <pre><code>{<br>  "monsterId": int,<br>  "id": int,<br>  "nom": "string",<br>  "pointDeVieBase": int,<br>  "forceBase": int,<br>  "defenseBase": int,<br>  "experienceBase": int,<br>  "spriteUrl": "string",<br>  "type1": "string",<br>  "type2": "string" or NULL<br>}<br></pre></code>                                                                   |
| ``/api/Monstre/id``   | GET    | Permet d'aller récupérer<br>toutes les informations<br>un monstre précis grâce<br>à son identifiant.      | `id` : `int` : identifiant du monstre dans la base de données                                                                                                                                                                                                                                                                                                |
| ``/api/Monstre/id``   | PUT    | Permet d'ajouter ou <br>modifier un enregistrement <br>à l'aide d'un identifiant <br>existant ou nouveau. | `id` : `int` : identifiant du monstre dans la base de données<br><br><pre><code>{<br>  "monsterId": int,<br>  "id": int,<br>  "nom": "string",<br>  "pointDeVieBase": int,<br>  "forceBase": int,<br>  "defenseBase": int,<br>  "experienceBase": int,<br>  "spriteUrl": "string",<br>  "type1": "string",<br>  "type2": "string" or NULL<br>} </pre></code> |
| ``/api/Monstre/id``   | DELETE | Permet de supprimer un <br>monstre précis de la base<br>de données.                                       | `id` : `int` : identifiant du monstre dans la base de données                                                                                                                                                                                                                                                                                                |
| ``/api/Monstre/nom``  | GET    | Permet d'aller récupérer<br>toutes les informations d'un<br>monstre précis grâce à son nom.               | `nom` : `string` : nom du monstre dans la base de données                                                                                                                                                                                                                                                                                                    |
| ``/api/Monstre/type`` | GET    | Permet de récupérer toutes<br>les informations de tous les<br>monstres ayant tel type.                    | `type` : `string` : type des monstres dans la base de données                                                                                                                                                                                                                                                                                                |

# Questions

- Est-ce qu’on devrait gérer une pagination vu la quantité assez grande de monstre ?
Avoir une pagination pourra être intéressante si on souhaite faire une liste de monstres, type pokedex.

- Quelle information spécifique pourrait être assez intéressant pour en faire un endpoint à lui seule.
Ça serait intéressant d'avoir un endpoint avec le nom des monstres car les utilisateurs lambdas ne connaissant généralement pas l'id des monstres.

- De quelle façon pourrait-on filtrer les données ?
Un filtre intéressant pourrait être les types des monstres. Filtrer pour avoir les monstres de tel type.
